# Git Commit Message Convention Rules

Selalu gunakan format commit message versi release untuk setiap update:
- **Format**: `release: vX.XX - [penjelasan singkat perubahan]`
- **Update Kecil (Minor/Patch)**: Tambahkan +0.01 versi dari sebelumnya (contoh: v1.0 -> v1.01, v1.01 -> v1.02).
- **Update Besar (Major)**: Tambahkan +1.0 versi dari sebelumnya (contoh: v1.0 -> v2.0).
